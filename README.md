## 🌟 Возможности и модули веб-сервиса (FR-01 — FR-18)

1. **Главная страница (`/`)**: Hero-секция с неоновым лаундж-стилем, счетчики оборудования (12 дорожек боулинга, 10 столов бильярда), витрина залов, интерактивный калькулятор тарифов.
2. **Каталог оборудования (`/catalog/`)** *(FR-01, FR-02)*: фильтрация по категориям (Боулинг, Русская пирамида, Американский пул, Снукер), статусу и ценовому диапазону.
3. **Интерактивная векторная SVG-карта залов (`/map/`)** *(FR-04)*: схема клуба с кликабельными дорожками, столами, зоной бара и ресепшн.
4. **Пошаговый мастер онлайн-бронирования (`/booking/`)** *(FR-03, FR-05, FR-06, FR-07, FR-10, FR-11)*:
   - Контроль лимита игроков: до 6 на дорожку боулинга (при 7+ игроках автоматическое предупреждение и предложение 2 дорожек по FR-05), до 4 на стол бильярда.
   - Динамический раздельный расчет цены относительно границы 18:00 (дневной и вечерний тарифы) без перезагрузки страницы.
   - Поддержка скидок по клубным картам Silver (5%), Gold (10%), Platinum (15%) по номеру карты (FR-17).
   - Модуль предзаказа блюд кухни и бара на дорожку (FR-08).
   - Защита от овербукинга и атомарная фиксация слота в БД (`transaction.atomic`, `select_for_update`).
5. **Оплата депозита и фискальный чек (`/payment/<id>/`)** *(FR-12)*: выбор оплаты банковской картой или по динамическому QR-коду СБП; генерация официального фискального чека по 54-ФЗ с QR-кодом, номерами ФН, ФД, ФПД и печатью.
6. **Личный кабинет гостя (`/my-bookings/`)** *(FR-14)*: поиск бронирований по номеру заказа (`SP-...`) или номеру телефона, просмотр состава предзаказа бара и отмена бронирования не позднее чем за 2 часа до игры.
7. **Меню кухни и бара (`/bar/`)** *(FR-08)*: ресторанный каталог с категориями (пицца из дровяной печи, бургеры, закуски, напитки, десерты).
8. **АРМ Администратора клуба (`/staff/dashboard/`)** *(FR-15, FR-16, FR-18)*:
   - Интерактивная временная шахматка (Time Grid) 22 ресурсов от 12:00 до 02:00.
   - Мгновенное изменение статусов сеанса («Сеанс активен», «Завершен», «Отмена / No-Show»).
   - Сводные оперативные KPI смены (выручка, занятость, брони).
   - Звуковые и визуальные оповещения о поступлении новых заказов.
9. **REST API (`/api/`)**:
   - `POST/GET /api/calculate-price/` — раздельный расчет стоимости день/вечер и клубной скидки;
   - `GET /api/available-resources/` — получение свободных ресурсов на интервал времени;
   - `GET /api/check-card/` — валидация номера дисконтной карты;
   - `GET /api/bar-items/` — получение меню бара.

## 🚀 Запуск веб-сервиса и тестов

Перейдите в каталог `backend`:
```powershell
cd backend
```

### 1. Запуск тестового сервера:
```powershell
python manage.py runserver
```
После запуска откройте в браузере: **http://127.0.0.1:8000/**

### 2. Запуск автоматических тестов:
```powershell
python manage.py test club_booking -v 2
```
*Успешный результат:* `Ran 13 tests in ...s — OK`

### 3. Проверка целостности системы:
```powershell
python manage.py check
```
